# wc

跨平台 `wc` — 打印每个文件的行数、词数和字节数。

## 概要

```
wc [选项]... [文件]...
```

## 选项

| 选项                      | 说明                                       |
| ------------------------- | ------------------------------------------ |
| `-c, --bytes`             | 打印字节数                                 |
| `-m, --chars`             | 打印字符数（支持多字节）                   |
| `-l, --lines`             | 打印行数                                   |
| `-w, --words`             | 打印词数                                   |
| `-L, --max-line-length`   | 打印最长行的长度                           |
| `--files0-from=F`         | 从 NUL 分隔的文件列表读取输入              |
| `--help`                  | 显示帮助并退出                             |
| `--version`               | 显示版本并退出                             |

## 说明

- 无选项时：等同于 `-l -w -c`。
- 多个文件：打印总计行。
- `-m` 使用 `mbrtowc()` 正确处理多字节字符。

## 示例

```bash
wc file.txt                  # 行数  词数  字节数
wc -l *.txt                  # 行数统计
wc -m file.txt               # 字符数（UTF-8）
wc -L file.txt               # 最长行长度
```

## 编译

```bash
gcc -O2 -std=c99 -Wall -o wc wc.c
```
