# date

显示或设置系统日期和时间。

## 概要
`
date [选项]... [+格式]
date -s 字符串
`

## 选项

| 选项                          | 说明                                       |
| ----------------------------- | ------------------------------------------ |
| -u, --utc, --universal      | 使用 UTC                                   |
| -d, --date=字符串           | 将字符串解析为日期                         |
| -I[FMT], --iso-8601[=FMT]  | ISO 8601 格式                              |
| -R, --rfc-email             | RFC 5322 格式                              |
| ` --rfc-3339=FMT`           | RFC 3339 格式                              |
| -r, --reference=文件        | 使用文件的修改时间                         |
| -s, --set=字符串            | 设置系统时间                               |
| ` --help`                   | 显示帮助并退出                             |
| ` --version`                | 显示版本并退出                             |

## 格式说明符

| 说明符 | 说明                   | 说明符 | 说明                   |
| ------ | ---------------------- | ------ | ---------------------- |
| %Y    | 年（YYYY）            | %m    | 月（01-12）            |
| %d    | 日（01-31）            | %H    | 时（00-23）            |
| %M    | 分（00-59）            | %S    | 秒（00-60）            |
| %s    | 自 epoch 以来的秒数   | %A    | 星期名                 |
| %B    | 月份名                 | %F    | YYYY-MM-DD             |
| %T    | HH:MM:SS               | %R    | HH:MM                  |

## 示例
`
date                          # 2025 年 1 月 15 日 星期三 14:30:00 UTC
date +%Y-%m-%d                # 2025-01-15
date +%s                     # 1736961000
date -d @1736961000          # 将 epoch 转换为日期
date -R                      # RFC 5322 格式
`

## 编译
`
gcc -O2 -std=c99 -Wall -o date date.c
`
