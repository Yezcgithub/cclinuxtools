# find

在目录层次结构中搜索文件。

## 概要
`
find [路径...] [表达式]
`

## 测试

| 测试                  | 说明                                     |
| --------------------- | ---------------------------------------- |
| -name 模式          | 匹配文件名（glob）                       |
| -iname 模式         | 匹配文件名（忽略大小写）                 |
| -path 模式          | 匹配完整路径                             |
| -regex 模式         | 用正则匹配路径                           |
| -type 类型          | 文件类型（f/d/l/b/c/s/p）               |
| -size N[cwbkMG]     | 文件大小测试                             |
| -empty              | 空文件或空目录                           |
| -mtime N            | N 天前修改                               |
| -atime N            | N 天前访问                               |
| -ctime N            | N 天前变更                               |
| -perm 模式          | 权限测试                                 |
| -newer 参照         | 比参照文件更新                           |
| -true / -false    | 始终为真 / 假                            |

## 动作

| 动作                  | 说明                                     |
| --------------------- | ---------------------------------------- |
| -print              | 打印路径（默认）                         |
| -print0             | 以 NUL 分隔打印路径                      |
| -ls                 | ls -dils 格式                            |
| -delete             | 删除找到的文件                           |
| -exec 命令 {} ;     | 执行命令                                 |
| -ok 命令 {} ;       | 确认后执行                               |
| -prune              | 不进入目录                               |
| -quit               | 立即退出                                 |

## 选项

| 选项                    | 说明                                     |
| ----------------------- | ---------------------------------------- |
| -maxdepth N           | 最大搜索深度                             |
| -mindepth N           | 最小搜索深度                             |
| ` ! 表达式`           | 取反                                     |
| ` ( 表达式 )`         | 分组                                     |
| ` 表达式 -a 表达式`   | 与（默认）                               |
| ` 表达式 -o 表达式`   | 或                                       |

## 示例
`
find . -name "*.c" -type f
find /tmp -mtime -7 -delete
find . -name "*.log" -exec grep -l error {} +
find . -maxdepth 2 -type d
`

## 编译
`
gcc -O2 -std=c99 -Wall -o find find.c
`
