# sed

跨平台 `sed` — 用于过滤和转换文本的流编辑器。

## 概要

```
sed [选项]... 脚本 [文件]...
sed [选项]... -e 脚本 [文件]...
sed [选项]... -f 脚本文件 [文件]...
```

## 选项

| 选项                | 说明                                       |
| ------------------- | ------------------------------------------ |
| `-e 脚本`           | 添加脚本到命令列表                         |
| `-f 脚本文件`       | 从文件读取脚本内容                         |
| `-n, --quiet`       | 抑制自动打印                               |
| `-r, -E`            | 使用扩展正则表达式                         |
| `-i[后缀]`          | 就地编辑文件（可选备份后缀）               |
| `-s`                | 将文件视为独立流                           |
| `--help`            | 显示帮助并退出                             |
| `--version`         | 显示版本并退出                             |

## 命令

| 命令      | 说明                                      |
| --------- | ----------------------------------------- |
| `s/正则/替换/标志` | 替换（标志：g, p, i, Nth）       |
| `a 文本`  | 在行后追加文本                            |
| `i 文本`  | 在行前插入文本                            |
| `c 文本`  | 用文本替换行                              |
| `d`       | 删除行                                    |
| `D`       | 删除到第一个换行符                        |
| `p`       | 打印行                                    |
| `P`       | 打印到第一个换行符                        |
| `n`       | 读取下一行到模式空间                      |
| `N`       | 将下一行追加到模式空间                    |
| `h`       | 将模式空间保存到保持空间                  |
| `H`       | 将模式空间追加到保持空间                  |
| `g`       | 将保持空间写入模式空间                    |
| `G`       | 将保持空间追加到模式空间                  |
| `x`       | 交换模式空间和保持空间                    |
| `b 标签`  | 跳转到标签                                |
| `t 标签`  | 替换成功时跳转                            |
| `T 标签`  | 替换失败时跳转                            |
| `q [退出码]` | 退出                                   |
| `r 文件`  | 读取文件内容                              |
| `w 文件`  | 将模式空间写入文件                        |
| `l`       | 打印非打印字符                            |
| `=`       | 打印当前行号                              |
| `y/源/目标/` | 字符转换                              |
| `: 标签`  | 定义标签                                  |
| `{ 命令 }`| 命令分组                                   |

## 示例

```bash
sed 's/old/new/g' file.txt
sed -i.bak 's/foo/bar/g' config.yml
sed -n '5,10p' file.txt           # 打印第 5-10 行
sed '/^#/d' config.txt            # 删除注释行
sed '1d' file.txt                 # 删除第一行
sed -E 's/[0-9]+/NUM/g' file.txt
```

## 编译

```bash
gcc -O2 -std=c99 -Wall -o sed sed.c
```
