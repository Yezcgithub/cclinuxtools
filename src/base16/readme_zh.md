# base16

使用 RFC 4648 Base16（十六进制：0-9A-F）编码/解码数据。

## 概要
`
base16 [选项]... [文件]...
`

## 选项

| 选项                      | 说明                                       |
| ------------------------- | ------------------------------------------ |
| -d, --decode            | 解码数据                                   |
| -i, --ignore-garbage    | 解码时忽略非字母字符                       |
| -w, --wrap=列数         | 在指定列数后换行（默认 76，0=不换行）     |
| ` --help`                | 显示帮助并退出                             |
| ` --version`             | 显示版本并退出                             |

## 说明

- 编码始终输出大写十六进制数字。
- 解码接受大小写。

## 示例
`
echo "Hello" | base16           # 48656C6C6F
echo "48656C6C6F" | base16 -d   # Hello
`

## 编译
`
gcc -O2 -std=c99 -Wall -o base16 base16.c
`
