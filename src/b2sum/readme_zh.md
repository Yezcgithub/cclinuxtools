# b2sum

计算 BLAKE2b 校验和（默认 512 位），按 RFC 7693 实现。

## 概要
`
b2sum [选项]... [文件]...
b2sum -c [选项]... [文件]...
`

## 选项

| 选项                        | 说明                                       |
| --------------------------- | ------------------------------------------ |
| -l, --length=位数         | 摘要长度（0-512，8 的倍数）               |
| -b, --binary              | 以二进制模式读取                           |
| -c, --check               | 从文件验证校验和                           |
| ` --tag`                   | 创建 BSD 风格输出                          |
| -t, --text                | 以文本模式读取（默认）                     |
| -z, --zero                | 每行以 NUL 结尾                           |
| ` --ignore-missing`        | 不因缺失文件而失败                         |
| ` --quiet`                 | 不打印验证成功的 OK                        |
| ` --status`                | 不输出；仅用退出码                         |
| ` --strict`                | 格式错误时非零退出                         |
| -w, --warn                | 对格式不正确的行发出警告                   |
| ` --help`                  | 显示帮助并退出                             |
| ` --version`               | 显示版本并退出                             |

## 示例
`
b2sum file.txt
b2sum -l 256 file.txt          # 256 位摘要
b2sum -c checksums.b2
`

## 编译
`
gcc -O2 -std=c99 -Wall -o b2sum b2sum.c
`
