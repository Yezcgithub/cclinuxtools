# less

跨平台 `less` — 交互式文件查看器。

## 概要

```
less [选项]... [文件]...
```

## 选项

| 选项                | 说明                                       |
| ------------------- | ------------------------------------------ |
| `-E, --quit-at-eof` | 到达文件末尾时退出                         |
| `-F, --quit-if-one-screen` | 文件适合一屏时退出                   |
| `-N, --LINE-NUMBERS`| 显示行号                                   |
| `-s, --squeeze-blank-lines` | 压缩连续空行                       |
| `-S, --chop-long-lines` | 截断长行（不换行）                     |
| `-R, --RAW-CONTROL-CHARS` | 透传 ANSI/控制字符                   |
| `-i, --ignore-case` | 搜索时忽略大小写                           |
| `-I, --IGNORE-CASE` | 搜索时忽略大小写（忽略非字母）             |
| `-p 模式`           | 跳转到第一个匹配                           |
| `-x N, --tabs=N`    | 设置制表符宽度为 N 个字符                  |
| `-J, --status-column` | 显示状态列                               |
| `-f, --force`       | 强制打开非普通文件                         |
| `-o 文件`           | 将输入复制到文件                           |
| `-P 字符串, --prompt=字符串` | 设置提示字符串                     |
| `+命令`             | 应用初始命令（`+N`、`+F`、`+/模式`）     |
| `--help`            | 显示帮助并退出                             |
| `--version`         | 显示版本并退出                             |

## 交互按键

| 按键          | 操作                               |
| ------------- | ---------------------------------- |
| `q` / `Esc`  | 退出                               |
| `Space` / `f`| 向前翻一屏                         |
| `b`           | 向后翻一屏                         |
| `j` / `Enter`| 向前滚动一行                       |
| `k`           | 向后滚动一行                       |
| `g`           | 跳到第一行                         |
| `G`           | 跳到最后一行                       |
| `/模式`       | 向前搜索                           |
| `?模式`       | 向后搜索                           |
| `n`           | 下一个匹配                         |
| `N`           | 上一个匹配                         |
| `h`           | 帮助                               |

## 示例

```bash
less file.txt
less -N file.txt               # 显示行号
less +50 file.txt              # 从第 50 行开始
ls -la | less                  # 管道输入
less +/error log.txt           # 从第一个 "error" 开始
```

## 编译

```bash
gcc -O2 -std=c99 -Wall -o less less.c
```
