# ls

跨平台 `ls` — 列出目录内容。

## 概要

```
ls [选项]... [文件]...
```

## 选项

| 选项               | 说明                                        |
| ------------------ | ------------------------------------------- |
| `-a, --all`        | 显示所有条目，包括 `.` 和 `..`              |
| `-A`               | 显示除 `.` 和 `..` 外的所有                 |
| `-l`               | 长格式（权限、所有者、组、大小、时间）      |
| `-h, --human`      | 人类可读大小（1K, 243M, 2G）               |
| `-R, --recursive`  | 递归列出子目录                              |
| `-C`               | 列式输出（检测终端宽度）                    |
| `--color[=WHEN]`   | 彩色输出（auto/always/never）               |
| `-F, --classify`   | 附加指示符（`/`, `*`, `@`, `=`, `|`）       |
| `-p`               | 在目录后附加 `/` 指示符                    |
| `-i, --inode`      | 打印每个文件的索引号                        |
| `-S`               | 按文件大小排序（最大优先）                  |
| `-t`               | 按修改时间排序（最新优先）                  |
| `-r, --reverse`    | 反转排序顺序                                |
| `-1`               | 每行一个文件                                |
| `-s, --size`       | 打印每个文件的分配大小                      |
| `--help`           | 显示帮助并退出                              |
| `--version`        | 显示版本并退出                              |

## 示例

```bash
ls                  # 列出当前目录
ls -la              # 长格式，显示所有文件
ls -lhtr            # 人类可读大小，按时间倒序
ls -R               # 递归
ls --color=always   # 彩色输出
```
