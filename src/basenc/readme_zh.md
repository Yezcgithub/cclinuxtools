# basenc

使用 RFC 4648 中指定的各种编码对数据进行编码/解码。

## 概要
`
basenc [选项]... [文件]...
`

## 编码类型

| 选项             | 字母表 / 说明                           |
| ---------------- | --------------------------------------- |
| ` --base64`     | RFC 4648 第 4 节（A-Za-z0-9+/）        |
| ` --base64url`  | RFC 4648 第 5 节（A-Za-z0-9-_）        |
| ` --base32`     | RFC 4648 第 6 节（A-Z2-7）             |
| ` --base32hex`  | RFC 4648 第 7 节（0-9A-V）             |
| ` --base16`     | RFC 4648 第 8 节（0-9A-F）             |
| ` --base2msbf`  | 位串，最高有效位优先                    |
| ` --base2lsbf`  | 位串，最低有效位优先                    |
| ` --z85`        | ZeroMQ Z85（输入必须是 4 字节的倍数）   |

## 通用选项

| 选项                      | 说明                                       |
| ------------------------- | ------------------------------------------ |
| -d, --decode            | 解码数据                                   |
| -i, --ignore-garbage    | 解码时忽略非字母字符                       |
| -w, --wrap=列数         | 在指定列数后换行（默认 76，0=不换行）     |
| ` --help`                | 显示帮助并退出                             |
| ` --version`             | 显示版本并退出                             |

## 编译
`
gcc -O2 -std=c99 -Wall -o basenc basenc.c
`
