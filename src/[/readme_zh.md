# [

检查文件类型和比较值。

## 概要
 `
test 表达式
[ 表达式 ]
` 

## 文件测试

| 测试      | 说明                                          |
| --------- | --------------------------------------------- |
| -e 文件 | 文件存在                                      |
| -f 文件 | 是普通文件                                    |
| -d 文件 | 是目录                                        |
| -r 文件 | 文件可读                                      |
| -w 文件 | 文件可写                                      |
| -x 文件 | 文件可执行                                    |
| -s 文件 | 文件存在且大小大于零                          |
| -L 文件 | 是符号链接                                    |
| -S 文件 | 是套接字                                      |
| -b 文件 | 是块设备                                      |
| -c 文件 | 是字符设备                                    |
| -p 文件 | 是命名管道                                    |
| -u 文件 | 文件设置了 setuid 位                          |
| -g 文件 | 文件设置了 setgid 位                          |
| -k 文件 | 文件设置了粘滞位                              |

## 字符串测试

| 测试           | 说明                                       |
| -------------- | ------------------------------------------ |
| -z 字符串    | 字符串为空                                 |
| -n 字符串    | 字符串非空                                 |
| 字符串1 = 字符串2 | 字符串相等                           |
| 字符串1 != 字符串2 | 字符串不相等                     |

## 整数测试

| 测试              | 说明                                     |
| ----------------- | ---------------------------------------- |
| 整数1 -eq 整数2 | 相等                                     |
| 整数1 -ne 整数2 | 不相等                                   |
| 整数1 -lt 整数2 | 小于                                     |
| 整数1 -le 整数2 | 小于等于                                 |
| 整数1 -gt 整数2 | 大于                                     |
| 整数1 -ge 整数2 | 大于等于                                 |

## 逻辑运算符

| 运算符     | 说明                                         |
| ---------- | -------------------------------------------- |
| ! 表达式 | 取反                                         |
| 表达式 -a 表达式 | 与                                   |
| 表达式 -o 表达式 | 或                                   |
| ( 表达式 ) | 分组                                      |

## 退出码

| 退出码 | 含义     |
| ------ | -------- |
| 0      | 真       |
| 1      | 假       |
| 2      | 错误     |

## 示例
 `
test -f file.txt && echo exists
test -z '`' && echo empty
[ 5 -gt 3 ] && echo yes
` 

## 编译
 `
gcc -O2 -std=c99 -Wall -o test test.c
`
