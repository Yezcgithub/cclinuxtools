# df

报告文件系统磁盘空间使用情况。

## 概要
`
df [选项]... [文件]...
`

## 选项

| 选项                        | 说明                                       |
| --------------------------- | ------------------------------------------ |
| -a, --all                 | 包含伪文件系统/重复/不可访问系统           |
| -B, --block-size=大小     | 按大小缩放                                 |
| -h, --human-readable      | 以 1024 为基数的人类可读格式               |
| -H, --si                  | 以 1000 为基数                             |
| -i, --inodes              | 列出 inode 信息而非块信息                  |
| -k                        | 等同于 --block-size=1K                   |
| -l, --local               | 仅限本地文件系统                           |
| ` --total`                | 显示总计                                   |
| -t, --type=类型           | 限于指定类型                               |
| -T, --print-type          | 打印文件系统类型                           |
| -x, --exclude-type=类型   | 排除指定类型                               |
| -P, --portability         | POSIX 输出格式                             |
| ` --help`                 | 显示帮助并退出                             |
| ` --version`              | 显示版本并退出                             |

## 示例
`
df -h                        # 人类可读格式
df -h /home                  # 指定挂载点
df -T                        # 显示文件系统类型
df -i                        # inode 使用情况
`

## 编译
`
gcc -O2 -std=c99 -Wall -o df df.c
`
