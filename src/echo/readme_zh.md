# echo

跨平台 `echo` — 显示一行文本。

## 概要

```
echo [选项]... [字符串]...
```

## 选项

| 选项        | 说明                                       |
| ----------- | ------------------------------------------ |
| `-n`        | 不输出尾部换行                             |
| `-e`        | 启用反斜杠转义解释                         |
| `-E`        | 禁用反斜杠转义解释（默认）                 |
| `--help`    | 显示帮助并退出（仅作为唯一参数时识别）     |
| `--version` | 显示版本并退出（仅作为唯一参数时识别）     |

## 转义序列（`-e`）

| 序列     | 说明             |
| -------- | ---------------- |
| `\a`     | 警报（响铃）     |
| `\b`     | 退格             |
| `\e`     | 转义             |
| `\f`     | 换页             |
| `\n`     | 换行             |
| `\r`     | 回车             |
| `\t`     | 水平制表符       |
| `\v`     | 垂直制表符       |
| `\\`     | 反斜杠           |
| `\0NNN`  | 八进制字节       |
| `\xHH`   | 十六进制字节     |
| `\uHHHH` | Unicode（16 位） |
| `\UHHHHHHHH` | Unicode（32 位） |

## 示例

```bash
echo "Hello, World!"
echo -n "no newline"
echo -e "line1\nline2"
echo -e "\x48\x65\x6c\x6c\x6f"   # Hello
```

## 编译
