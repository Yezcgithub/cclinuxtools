# cd

跨平台 cd -- 切换工作目录。

## 概要
 ``ncd [选项]... [目录]
`` 

## 选项

| 选项               | 说明                                       |
| ------------------ | ------------------------------------------ |
| `-L, --logical`    | 遍历时使用 PWD（默认）                  |
| `-P, --physical`   | 解析最终路径中的符号链接                   |

## 行为

- 无参数时回到 HOME。
- cd dash 返回上一个目录并打印。
- 支持波浪号展开。
- 支持 CDPATH 搜索。

## 示例
 ``ncd /usr/local
cd -                # 返回上一个目录
cd ~                # 回到主目录
cd ../src           # 相对路径
`` 

## 编译
 ``ngcc -O2 -std=c99 -Wall -o cd cd.c
``
