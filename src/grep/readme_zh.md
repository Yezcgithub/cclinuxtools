# grep

跨平台 `grep` — 在文件中搜索模式。

## 概要

```
grep [选项]... 模式 [文件]...
```

## 模式选项

| 选项        | 说明                               |
| ----------- | ---------------------------------- |
| `-G`        | 基本正则表达式（默认）             |
| `-E`        | 扩展正则表达式（ERE）              |
| `-F`        | 固定字符串（非正则）               |
| `-e 模式`   | 使用模式进行匹配                   |
| `-f 文件`   | 从文件获取模式                     |

## 匹配选项

| 选项        | 说明                               |
| ----------- | ---------------------------------- |
| `-i, -y`    | 忽略大小写                         |
| `-v`        | 反向匹配                           |
| `-w`        | 仅匹配完整单词                     |
| `-x`        | 仅匹配整行                         |
| `-m NUM`    | 匹配 NUM 次后停止                  |

## 输出选项

| 选项        | 说明                               |
| ----------- | ---------------------------------- |
| `-n`        | 在每行前添加行号                   |
| `-b`        | 在每行前添加字节偏移               |
| `-c`        | 仅打印匹配行的计数                 |
| `-o`        | 仅打印匹配部分                     |
| `-l`        | 仅打印包含匹配的文件名             |
| `-L`        | 仅打印不包含匹配的文件名           |
| `-q`        | 安静模式：无输出，仅退出状态       |
| `-H`        | 始终打印文件名                     |
| `-h`        | 不打印文件名                       |
| `--color[=WHEN]` | 高亮匹配                       |

## 上下文选项

| 选项          | 说明                             |
| ------------- | -------------------------------- |
| `-A NUM`      | 打印匹配后 NUM 行               |
| `-B NUM`      | 打印匹配前 NUM 行               |
| `-C NUM`      | 打印匹配前后 NUM 行             |

## 递归选项

| 选项                   | 说明                             |
| ---------------------- | -------------------------------- |
| `-r, -R`               | 递归读取所有文件                 |
| `--include=PATTERN`    | 仅包含匹配的文件                 |
| `--exclude=PATTERN`    | 排除匹配的文件                   |
| `--exclude-dir=PATTERN`| 排除匹配的目录                   |
| `-a, --text`           | 将二进制文件视为文本             |
| `-I`                   | 跳过二进制文件                   |

## 示例

```bash
grep "error" log.txt
grep -r "TODO" src/
grep -i "hello" file.txt
grep -n "pattern" file.txt
grep -c "error" log.txt
grep -E "^[0-9]+" data.txt
grep -A3 -B1 "exception" app.log
```

## 编译
