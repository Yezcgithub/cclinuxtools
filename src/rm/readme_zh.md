# rm

跨平台 `rm` — 删除文件或目录。

## 概要

```
rm [选项]... 文件...
```

## 选项

| 选项                      | 说明                                     |
| ------------------------- | ---------------------------------------- |
| `-f, --force`             | 强制删除，忽略不存在的文件，不提示       |
| `-i`                      | 每次删除前提示                           |
| `-I`                      | 删除超过 3 个文件或递归删除前提醒一次    |
| `-r, -R, --recursive`     | 递归删除目录及其内容                     |
| `-d, --dir`               | 删除空目录                               |
| `-v, --verbose`           | 显示操作过程                             |
| `--preserve-root`         | 拒绝操作 `/`（默认）                    |
| `--no-preserve-root`      | 允许操作 `/`                             |
| `--one-file-system`       | 跳过不同文件系统上的目录                 |
| `--help`                  | 显示帮助并退出                           |
| `--version`               | 显示版本并退出                           |

## 说明

- 永远不删除 `.` 或 `..` 组件。
- 默认拒绝操作 `/`。

## 示例

```bash
rm file.txt
rm -f tempfile
rm -rf old_project/
rm -i *.bak
```

## 编译

```bash
gcc -O2 -std=c99 -Wall -o rm rm.c
```
